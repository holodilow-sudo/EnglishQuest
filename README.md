# English City Quest

Android-тренажёр английского: учебный курс, повторение слов, блиц и английский для путешествий.

## Скачать и обновить

Готовые APK публикуются в [Releases](https://github.com/holodilow-sudo/EnglishQuest/releases). Требуется Android 8.0 или новее.

Устанавливайте новую APK **поверх существующего приложения**, не удаляя его и не очищая данные. Это сохраняет локальный прогресс, слова и награды.

Пакет приложения: `ru.arseniy.englishquest`. Выпуски подписываются одним и тем же ключом. Контрольная сумма SHA-256 прилагается к каждому APK.

## Выпуски

Стабильные версии: тег `vX.Y.Z`, файл `EnglishQuest-X.Y.Z.apk`. Новая версия должна иметь больший Android versionCode и прежнюю подпись. Черновики и предварительные версии не предназначены для обычного обновления.

В версии 1.2.0 есть тренировки по курсу, 20 тем путешествий и настраиваемые напоминания. Автоматическая проверка обновлений через GitHub готовится для следующей версии.

Исходный курс работает без интернета. Для новых фраз используется английский голос Android; его доступность зависит от устройства.

Этот репозиторий служит для распространения выпусков. Ключ подписи и личный прогресс здесь не хранятся.
