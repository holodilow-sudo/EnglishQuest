# English City Quest

Android-тренажёр английского: учебный курс, повторение слов, блиц и английский для путешествий.

## Скачать и обновить

[Скачать APK 1.2.2](https://github.com/holodilow-sudo/EnglishQuest/releases/download/v1.2.2/EnglishQuest-1.2.2.apk) · [Все выпуски](https://github.com/holodilow-sudo/EnglishQuest/releases). Требуется Android 8.0 или новее.

Устанавливайте новую APK **поверх существующего приложения**, не удаляя его и не очищая данные. Это сохраняет локальный прогресс, слова и награды.

Пакет приложения: `ru.arseniy.englishquest`. Выпуски подписываются одним и тем же ключом. Контрольная сумма SHA-256 прилагается к каждому APK.

## Обновления внутри приложения — с версии 1.2.2

Установите 1.2.2 поверх старой версии прежним способом один раз. После этого приложение само проверяет новые стабильные выпуски при открытии и скачивает APK без браузера.

Во время загрузки виден процент; можно продолжать заниматься, остановить загрузку или повторить её при ошибке. После проверки файла появляется кнопка **«Установить»**. Она открывает системное подтверждение Android. При первом использовании Android может попросить разрешить установку из English City Quest; затем вернитесь в приложение и нажмите «Установить».

Скачанный файл сохраняется в кэше и проверяется снова перед установкой. Если Android очистит кэш, приложение скачает его заново. Проверяются SHA-256, пакет, версия и подпись APK.

Во время урока или блица предложение установки ждёт возвращения на главный экран. В профиле есть кнопка «Проверить сейчас». Без интернета занятия доступны; прогресс и ответы в GitHub не отправляются. Вход в GitHub и ключи на телефоне не нужны.

Версия 1.2.1 умеет автоматически проверять обновления, но скачивает через браузер.

## Выпуски

Стабильные версии: тег `vX.Y.Z`, файл `EnglishQuest-X.Y.Z.apk`. Новая версия должна иметь больший Android versionCode и прежнюю подпись. Черновики и предварительные версии не предназначены для обычного обновления.

Сохранены тренировки по курсу, 20 тем путешествий и настраиваемые напоминания из версии 1.2.0. Исходный курс работает без интернета. Для новых фраз используется английский голос Android; его доступность зависит от устройства.

Репозиторий содержит исходники приложения и готовые выпуски. Ключ подписи и личный прогресс здесь не хранятся.

## Исходники

- `app/` — интерфейс, учебный курс, тренировки и путешествия.
- `android/src/main/` — Android-оболочка, уведомления, обновления, ресурсы и аудио.
- `scripts/` и `android/tools/` — сборка, подготовка материалов и проверки.
- `docs/` — описание учебной логики и разработки.

[Инструкция разработчика](docs/source-development.md). Публичная копия обезличена: персональные настройки, два аудиоприветствия с личным именем и локальные пути исключены. Технические идентификаторы приложения и прогресса сохранены. Готовая APK 1.2.2 остаётся прежней.
