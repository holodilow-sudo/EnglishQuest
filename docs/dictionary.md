# Дополнительный словарь

`scripts/merge-dictionary.cjs` читает все `tmp/dictionary/entries-*.json`, объединяет их в `content-dictionary.json` и создаёт `app/content.js` на основе **неизменённого** `content-full.json`.

В приложение входят слова, переводы, произношение и упражнения. PDF, сканы страниц и OCR-файлы в содержимое приложения не добавляются.

Текущий состав: **2135 словарных статей и 187 словарных уроков**; вместе с тематическим курсом — **2365 карточек, 232 урока, 2585 заданий**.

В исходном PDF **отсутствует печатная страница 207**. Лексический промежуток `piano…purring` (99 статей) дополнен по словарю издания **2014 года**, печатным страницам **192–193**, PDF-страницам **193–194**. Тождество страниц разных изданий не подтверждено. Значение `page:207` у этих записей — место группы внутри алфавитного маршрута; оно не выдаётся за проверенную страницу источника.

Файл дополнения: `tmp/dictionary/entries-207-restored.json`. Его `sourceEdition`, `sourceAlternatePage`, `sourceURL` и `sourceNote` сохраняются в объединённом словаре. У записей `sourcePdfPage:null`. В карточках и заданиях интерфейс показывает **«изд. 2014 · стр. 192/193»**. Справка профиля объясняет источник дополнения.

## Данные и прогресс

- Четыре тематических юнита и их 22 секции остаются в `CONTENT.units`. Дополнительный раздел — `CONTENT.dictionaryUnit`, id `-1`.
- Словарные секции сгруппированы по печатной странице. Поэтому добавление отсутствовавшей страницы не меняет номера существующих секций и уроков.
- Дубликаты одинаковых `en + ru` внутри словаря объединяются. Разные значения одного слова сохраняются, включая `speechText`, `partOfSpeech`, `forms`, `ipa` и замечания о печатном источнике.
- Тематические карточки сохраняют собственные ID и контекстные примеры. Словарная карточка того же слова может существовать отдельно: это не сбрасывает ранее накопленный прогресс тематического курса.
- ID карточки и задания основан на SHA-256 нормализованной пары `en|ru`; порядок слияния не влияет на начисленный XP.
- Генератор явно различает омограф `close`: при `partOfSpeech:"verb"` («закрывать») используется `speechText:"to close"`, при `partOfSpeech:"adverb"` («близко») — `speechText:"close"`. Ключи /z/ и /s/ поэтому не смешиваются в встроенной озвучке. Регрессия проверяет словарь, карточки и вопросы.
- Каждый словарный урок содержит до 12 карточек. Остаток равномерно распределён между уроками страницы; короткого последнего урока менее 5 карточек нет.
- Каждая статья имеет одно задание английский → русский. Обратный перевод автоматически не создаётся, чтобы не требовать единственный английский вариант для русского синонима.
- Отвлекающие ответы выбраны из консервативного набора конкретных понятий. Исключаются совпадающие русские корни, одинаковые ответы и английские слова/синонимы текущей статьи. Порядок вариантов детерминирован.
- Уже существующие правила XP, 10 монет за освоение урока, дневной цели и повторения трудных слов действуют и для словаря. Тематические значки остаются привязаны к исходным 22 секциям и четырём юнитам.

## Интерфейс

Пятая плитка курса открывает словарь. В списке карточек есть фильтры по разделу/словарной странице и поиск. Первоначально выводятся 60 карточек; следующие 60 добавляются кнопкой. Пустой пример не занимает места в карточке и не создаёт кнопку озвучки. Для омографов используются отдельные `speechText`, например `a record` и `to record`, как в карточках, так и в заданиях. В профиле и справке указано: встроенная озвучка — **американский английский (en-US)**; в учебнике встречаются британские формы и транскрипция.

Подписи различают печатные страницы словаря (`стр. учебника`) и страницы PDF тематического курса (`стр. PDF`). Это ссылки на источник, сами страницы не встроены.

## Проверки

```powershell
node scripts/merge-dictionary.cjs
node --check app/content.js
node --check app/app.js
node scripts/verify-dictionary.cjs
node scripts/verify-rewards.cjs
```

Проверки браузера используют новый временный Chrome-контекст и не обращаются к личному профилю. Отчёт словаря: `tmp/dictionary-verification.json`; скриншоты: `preview/full-dictionary-*.png`.

`content-dictionary.json.missingPrintedPages` отражает **непроверенные страницы исходного PDF** и остаётся `[207]` после дополнения из другой редакции. `uncoveredPrintedPageSlots:[]` означает, что алфавитные группы заполнены, а не подтверждает тождество страниц. `alternateSources` содержит сведения об альтернативном издании; `supplementedEntries:99` — число дополненных статей. Новые файлы `entries-*.json` автоматически попадают в следующее слияние.
