# Исходники и сборка

В репозитории размещены исходники на основе выпущенной версии 1.2.2: Android-оболочка, интерфейс, учебные задания, изображения, безопасные аудиоресурсы и скрипты подготовки/проверки.

## Приватность

Публичная копия обезличена. В интерфейсе используется «Ученик», в примерах — вымышленное имя Alex. Возраст и отдельная запись персонального профиля удалены. Две озвученные фразы с личным именем исключены; для отсутствующих записей Android использует системный английский голос. Остальные 2631 встроенные аудиозаписи сохранены.

Технические идентификаторы Android-пакета и хранилища прогресса сохранены для совместимости. В репозитории нет реальных сохранений, истории ответов, резервных копий устройства, локальных путей пользователя, ключа подписи или пароля. Опубликованная APK 1.2.2 этим добавлением исходников не заменялась.

## Просмотр интерфейса

Установите Node.js, затем выполните `node scripts/serve.cjs` и откройте `http://127.0.0.1:4173`. Проверка структуры курса: `node scripts/validate-content.cjs`.

Для браузерных тестов установите Playwright командой `npm install --no-save playwright` и используйте установленный Chrome. Например: `node scripts/verify-training-travel.cjs`. Скрипты используют временные тестовые профили и синтетический прогресс.

## Android

Сборщик рассчитан на Windows, Python 3, Node.js, JDK 17 и Android SDK API 35. Gradle и внешние Android-библиотеки не используются. Поместите JDK в `.toolchain/jdk/`, Android build-tools в `.toolchain/sdk-build/`, платформу API 35 в `.toolchain/sdk-platform/`. Сборщик ищет инструменты внутри этих каталогов. Нужны `aapt2.exe`, `zipalign.exe`, `d8.bat`, `lib/apksigner.jar`, `core-lambda-stubs.jar` и `android.jar`.

Ключ подписи предоставляет владелец отдельно. Задайте в локальном окружении:

- `ENGLISHQUEST_KEYSTORE` — путь к существующему закрытому хранилищу;
- `ENGLISHQUEST_STORE_PASSWORD` — пароль хранилища;
- `ENGLISHQUEST_KEY_ALIAS` — псевдоним ключа (по умолчанию прежний технический alias);
- `ENGLISHQUEST_KEY_PASSWORD` — пароль ключа, если отличается от пароля хранилища.

Не записывайте значения паролей в файлы репозитория или команды, сохраняемые в истории. Передавайте их из локального менеджера секретов. Сборщик передаёт пароли `apksigner` через переменные окружения; автоматически новый ключ не создаёт. Чтобы обновлять уже установленное приложение, нужен прежний ключ подписи.

Команда сборки:

```text
python scripts/build-android.py --allow-system-city-speech --allow-system-travel-speech
```

Результат появится в игнорируемом `dist/`. Это обезличенная сборка исходников; её аудиопокрытие отличается от готовой APK в Releases на две удалённые персональные записи. Новые версии должны иметь увеличенные versionName/versionCode; не подменяйте существующие опубликованные APK.

Java-проверки без устройства находятся в `android/tools/UpdateReleaseTest.java`, `UpdateTransferTest.java`, `ReminderScheduleTest.java`. Для JSON-тестов нужен `org.json:json:20240303` как зависимость только тестов; в APK библиотека не входит. `scripts/check-inapp-updates-native.cjs` ожидает эту JAR в `work/github-update-check/json-20240303.jar` и указанные в нём локальные каталоги SDK/JDK.

Учебные материалы и AAC уже включены. Скрипты `android/tools/prepare-speech.cjs`, `generate-speech.ps1` и `encode-speech.py` позволяют подготовить новые записи через Windows SAPI и локальный ffmpeg. Скан учебника и исходные WAV в репозиторий не включаются.
